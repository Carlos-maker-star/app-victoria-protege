# La Victoria Protege · Web (central de monitoreo)

Panel web para operadores, supervisores y administradores. Angular 22 + Angular Material + Tailwind 4,
mapa con Leaflet (OpenStreetMap) y tiempo real por WebSocket (STOMP).

```bash
npm install
npm start          # http://localhost:4200  (el backend debe estar en :8080)
npm test           # pruebas (Vitest)
npm run build      # build de producción en dist/
```

Más información en [`../CLAUDE.md`](../CLAUDE.md).
